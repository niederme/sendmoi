# SendMoi 1.4 release handoff

The repository is set to version 1.4, build 168, for the app and share extension on iOS and macOS. The builds have been submitted to App Store Connect per the September 28, 2026 user report. Review status, selected build numbers, approval, and public availability have not been independently verified here and must be checked for each platform.

## Candidate changes

- Updated the app icon and added it to the macOS share extension.
- Improved link previews, including images from pages that block ordinary metadata requests.
- Let share previews return without waiting for AI summaries, and improved email preview fallback behavior.
